# Eaglercraft Manhunt – HTML-Datei

**Download:** [Eaglercraft-Manhunt.html](Eaglercraft-Manhunt.html) anklicken und dann rechts oben auf
das Download-Symbol („Download raw file“) klicken. Die Datei ist ca. 77 MB groß.

Direkter Download-Link:
https://github.com/justusvoelkle3141592654-ux/HTML-TO-Apk/raw/claude/eaglecraft-manhunt-mod-rf1tmx/HTML-Datei/Eaglercraft-Manhunt.html

## Starten

1. Die heruntergeladene Datei im Browser öffnen (Chrome, Edge oder Firefox). Funktioniert auch offline.
2. Profil bestätigen („Done“).
3. Einzelspieler → „Manhunt-Welt“ → Play Selected World.
4. Menü mit Taste **M**: Rolle wählen, Hunter-Bots einstellen, Runde starten.
